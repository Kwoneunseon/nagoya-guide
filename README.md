# 나고야 스토리 가이드북

나고야 3박 4일 여행용 모바일 웹 가이드북입니다. 서버 없이 파일만으로 동작합니다.

## 파일 구성

| 파일 | 역할 | 수정할 일 |
|---|---|---|
| `data.js` | 모든 글, 사진, 퀴즈, 미션, 용어 사전 | **자주 수정** |
| `index.html` | 화면 뼈대, 지도 배경 그림 | 거의 없음 |
| `style.css` | 색, 글꼴, 레이아웃 | 디자인 바꿀 때만 |
| `app.js` | 탭, 팝업, 아코디언 동작 | 거의 없음 |

`main.html` 은 처음 초안 파일이라 사이트에는 쓰이지 않습니다.

## 보는 법

`index.html` 을 더블클릭해서 브라우저로 열면 됩니다. 사진은 인터넷에서 불러오므로 인터넷 연결이 필요합니다.

## 콘텐츠 수정 가이드 (`data.js`)

메모장, VS Code 같은 편집기로 `data.js` 를 열어 고칩니다. 저장 후 브라우저를 새로고침하면 바로 반영됩니다.

### 꼭 지킬 규칙 3가지

1. 글은 항상 `"큰따옴표"` 안에 씁니다. 글 안에 큰따옴표를 쓰려면 `\"` 처럼 앞에 `\` 를 붙입니다.
2. 항목 사이에는 쉼표 `,` 를 넣습니다. 목록의 마지막 항목 뒤 쉼표는 있어도 없어도 됩니다.
3. 괄호 `{ }`, `[ ]` 의 짝이 맞아야 합니다. 화면이 하얗게 나오면 대부분 이 셋 중 하나가 문제입니다.

### 글 고치기

원하는 문장을 찾아 따옴표 안의 글만 바꾸면 됩니다.

```js
body: [
  "첫 번째 문단입니다.",
  "두 번째 문단입니다."
],
```

`body` 의 한 줄이 화면의 한 문단이 됩니다.

### 스폿 추가하기

해당 날짜(`days` 안의 `day1`~`day4`)의 `spots: [ ... ]` 안에 기존 스폿 하나를 통째로 복사해 붙이고 내용을 바꿉니다. **`id` 는 다른 스폿과 겹치지 않게** 새로 정해 주세요.

```js
{
  id: "d1-osu",                 // 겹치지 않는 영어 이름
  time: "오후",                  // 시간 칩
  title: "오스 상점가",
  question: "카드 위쪽 갈색 질문",  // 없어도 됨
  photo: {                      // 없으면 photo 줄 전체를 지우면 됨
    src: "사진 주소",
    alt: "사진 설명",
    credit: "© 저작자 / CC BY-SA 4.0",
    link: "사진 출처 페이지 주소"
  },
  body: ["문단 1", "문단 2"],
  tip: "회색 상자 팁",             // 없어도 됨
  tags: ["Flavors"],            // 없어도 됨
  quiz: [
    { q: "질문", a: "정답" }
  ],
  missions: [
    { title: "미션 제목", detail: "미션 설명" }
  ]
},
```

`question`, `photo`, `tip`, `tags`, `quiz`, `missions` 는 필요 없으면 그 줄을 지워도 됩니다.

### 용어 팝업 넣기

1. 본문에 `[[히츠마부시]]` 처럼 대괄호 두 개로 감쌉니다.
2. 맨 아래 `glossary` 에 같은 이름으로 설명을 추가합니다.

```js
"히츠마부시": { jp: "ひつまぶし", desc: "설명 문장" },
```

보이는 글자와 사전 이름이 다르면 `[[보이는 말|사전 이름]]` 으로 씁니다. 예: `[[이에야스|도쿠가와 이에야스]]`

사전에 없는 이름을 쓰면 팝업 없이 일반 글자로 보입니다.

### 사진 바꾸기

`photo` 의 `src` 에 사진 주소를 넣습니다. 두 가지 방법이 있습니다.

- **인터넷 사진**: Wikimedia Commons에서 사진을 열고, 사진 주소를 복사해 붙입니다. 저작자와 라이선스를 `credit` 에 적어 주세요(CC BY, CC BY-SA 라이선스는 표기가 의무입니다).
- **내 사진**: 이 폴더에 `images` 폴더를 만들고 사진을 넣은 뒤 `src: "images/castle.jpg"` 처럼 씁니다. 내 사진이면 `credit` 줄은 지워도 됩니다.

### 지도 핀 옮기기

`map` 에서 `x`, `y` 숫자를 바꾸면 핀이 움직입니다. 지도 크기는 가로 520, 세로 380 기준입니다. `spot` 은 핀을 눌렀을 때 이동할 스폿의 `id` 입니다. 이름표를 핀 왼쪽에 두려면 `align: "left"` 를 붙입니다.

### 테마 카드 고치기

`themes` 안의 네 항목이 첫 화면 카드와 "테마별 스토리" 탭을 함께 만듭니다. `card` 는 첫 화면 카드의 짧은 문구, `sections` 는 테마 탭의 소제목과 문단입니다.

## 배포 (GitHub Pages)

1. GitHub에 새 저장소를 만들고 이 폴더의 파일을 올립니다.
2. 저장소 **Settings → Pages** 에서 Branch를 `main`, 폴더를 `/ (root)` 로 고르고 저장합니다.
3. 몇 분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소로 열립니다.

Netlify를 쓴다면 이 폴더를 Netlify Drop 페이지에 끌어다 놓아도 됩니다.
